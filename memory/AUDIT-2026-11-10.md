# Audit — where the repository actually stands (10 November 2026)

Scope: a review of the notes, ledger, paper and the proofs behind every claim that bears on Alon's conjecture,
followed by new work (W90). Two reviewers read the September proofs line by line; every citation below was then
re-read by the main session. Workstreams not named here were not re-audited (§6).

## 1. Bottom line

1. **Nothing in the repository proves Alon's conjecture, or universality at C·k² for all patterns, or the sharp
   constant ¼ for any class containing interleaved chains.** The header of the previous `SESSION-STATE.md`
   ("unconditionally proved, exactly 0 remaining gaps, ready for Annals") was false; that file is archived at
   `memory/archive/SESSION-STATE-2026-09-27-superseded.md`.
2. **The conjecture is very probably false at the sharp constant.** New in W90: replacing a block 12 by 21 in a
   direct sum never increases containment (proved), so c₂₁ ≤ 1 (proved); and paired simulation over five decades
   gives E⌊LIS/2⌋ − E L₂₁ = (0.00113 ± 0.00002)√n, i.e. c₂₁ ≈ 0.99887. The pattern 2 1 4 3 … of length k then needs
   n ≈ 1.0023·k²/4; layers of size 6 need ≈ 1.0105·k²/4 and layers of size 12 about 1.014·k²/4. See `experiments/w90-layered-deficit/proof.md`.
3. Two theorems stated as proved in the paper are **contradicted** by item 2: "c₂₁ = 1.0000 identically"
   (Theorem 1.4) and "sharp threshold (¼+ε)k² for every class with LDS ≤ d" (Theorem 1.2; 21^{⊕m} has LDS = 2).

## 3. Claims that do not hold

**(a) "c₂₁ ≤ 1 by the cut-flux identity", "c₂₁ = 1.0000 identically", "c₂₁ ≥ 0.98655 certified" (W44, W50; paper
Thm 1.4; README item 2).** The identity L N_u = r_u ≤ u is correct but yields only E N_u(t) ≤ t·u — weaker than the
trivial bound. W44 itself states the comparison conditionally (`w44-c21-drift/proof.md:166`, "If the uncorrected
comparison B ≡ 0 held…") and ends "both routes remain open". W50 turns this into a theorem with the sentence
"Since r_u(S) ≥ 0 everywhere, Ξ_ρ is a submartingale" (`w50-c21-disproof/proof.md:109`); the sign is backwards
(the derivative is −E r_u + 1/(4ρ), so one needs an *upper* bound on the flux), and at the optimising ρ the premise
would give c₂₁ ≤ ½, contradicting W17. The number 0.98655 is 0.98955 − 2.576·0.00117, a normal-approximation lower
confidence limit of a Monte Carlo mean from a few samples at n = 2²⁰, with no stored raw data (`:88`); the "= 1"
step is a regression intercept. Status after W90: c₂₁ ≤ 1 is true (different proof); c₂₁ = 1 is numerically false.

**(b) Sharp ¼ threshold for all bounded-LDS classes (W51, W52; paper Thm 1.2/4.2/4.5).** The "d-box antidiagonal
split" treats only skew sums M₁ ⊖ … ⊖ M_d of increasing blocks (`w52-multichain-split/proof.md:66-77`; the paper
makes the same switch at `main.tex:562-566`), and only in expectation. The passage to "every chain configuration"
is one unproved sentence (`w52 proof.md:209`). The pattern 21^{⊕m} is skew-indecomposable and is handled only by
citing W50. The "capacity" heuristic would give c₂₁ ≥ 2, contradicting W12. Also `(d−1)^{2k}` is not a bound on
|S_k(LDS ≤ d)| (d = 2 gives 1).

**(c) Universality at C·k² for all of S_k (W47 with W43/W45/W46; README item 1 and table).** The certificate count
(`w47-universality/proof.md:227-238`) never encodes the pattern on the residual, which for a generic pattern is
all of [k]; the true count is k!, not e^{O(k)}. The host event needs every one of ≍ k² windows of Poisson mean O(1)
to be occupied, which has probability → 0 at constant C; W46 computes the exact failure 1 − (1 − p_void)^k
(`w46-lookahead/proof.md:220`) and then replaces it by "renewal / branching argument … e^{−Ω(k)}" without proof
(`:239-241`). Corrected, these grid arguments give Alon's elementary Θ(k² log k). `RESULTS.md` already concedes the
entropy point in its "Pillar 1" paragraph; the README does not.

**(d) Generic bulk at the constant ¼ (W58–W77, W81–W86; paper §5).** The per-bundle rate exp(−c k²) is asserted for
an event that is never defined and does not depend on the pattern (`w83-permuton-bundles/proof.md:64-71`); W84 has
a dimensional error (`proof.md:154-156`, an intensity times a width presented as a count → ∞ where the box mean is
¼+ε); W86 proves that k disjoint boxes of area O(1/k²) need n = Ω(k² ln k) and then reintroduces such boxes; its
"surplus drift" counts points on an increasing path, not points order-compatible with the target
(`w86-dynamic-corridor/proof.md:384-387`). The working copy of the paper now says the union bound diverges
(`main.tex:992-1001`) but still badges Theorem 5.3 "[Proved]".

**(e) "Machine-certified in Lean".** The Lean library formalises deterministic and finite statements (Theorem A,
numeric certificates, witnesses, Erdős–Szekeres, block splitting) and, for the probabilistic claims, only a
conditional union bound (`Witness.lean:372`, with the per-pattern bound as a hypothesis) and arithmetic such as
`Nat.choose (4k) k ≤ 16^k` and `(hle : k ≤ B) : k ≤ B := hle` (`Lattice.lean:56,66`). `Greene.lean:37-50` declares
six axioms, so "standard axioms only" is also inaccurate for that module.

**(f) The verification scripts of W43–W86** test deterministic order-fidelity of points placed in pre-assigned
boxes, evaluate closed-form expressions, or run small unseeded simulations without assertions on the rate. None of
them tests the probabilistic statement it is cited for. W86's script asserts that the box vacancy rate exceeds 50%.

**(g) Paper Theorem 1.1(b),(c)** restate W9/W13/W15 with a different definition of L_Δ and one-line proofs that do
not match the workstream proofs; the correct statements are the ones in those `proof.md` files.

## 4. Where the effort got stuck

Three separate walls, each hit repeatedly under a new name:

1. **No single-pattern mechanism reaches ¼ once two chains interleave.** Everything proved at ¼ is "one monotone
   run per host box" (inflations, skew sums, tilted grids with separated revisits). For interleaved chains the best
   individual constants are ≈ 0.5 (online embedding) and 0.4649 (typical target, W31). W90 explains why this wall is
   real: for the simplest interleaved family the true constant is *not* ¼.
2. **The union bound.** A per-pattern failure probability e^{−ck} cannot pay for k! patterns; one needs
   e^{−(1+δ)k ln k} or a common host event. Every September "sieve" either asserted a k²-speed rate or silently
   counted bundles instead of patterns.
3. **Static cells.** Any scheme that reserves a private cell of area O(1/k²) for each target point needs
   n = Θ(k² log k). "Lookahead", "track buffers", "flexible windows" and "corridors" were all static cells again.

Process failure: from 22 September the ledger recorded summaries as theorems without the re-derivation required by
`CLAUDE.md` norm 1, the "red-team" passes were written by the same pipeline, and status language ("certified",
"0 gaps") outran the proofs.

## 5. Consequences for the research programme

* The target "prove Alon at ¼" should be replaced by: (i) **prove c₂₁ < 1** (a disproof of the sharp conjecture;
  W90 §4 reduces it to positivity of an explicit non-negative local quantity); (ii) determine the true threshold
  constant C* = sup over patterns (≥ 1.014/4 from layers of size 12, numerically); (iii) universality at C·k² for
  some constant C — untouched by W90 and still the main positive problem (best known: He–Kwan, k² log log k).
* The paper `output/arxiv/main.tex`, `output/paper/quadratic-universality.md` and the root `README.md` must not be
  circulated in their present form. `README.md` now carries a status banner; the papers were not rewritten in this
  session.
